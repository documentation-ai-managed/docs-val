## Creating Your First Doc

1. Log in at `https://valdocs.com`
2. Click **New Project** in the dashboard
3. Enter a name for your documentation space
4. Click **Create**
5. Select **Add Page** to start writing
6. Use the editor to add content, images, and code blocks
7. Click **Publish**

Your documentation is now available to your team!
