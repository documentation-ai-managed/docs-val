## Overview

Val provides your default documentation space to organize and manage project documentation effortlessly. You create structured guides, API references, and changelogs in one centralized location. Benefit from MDX-powered pages with interactive components like tabs, steps, and cards to enhance user experience.

Val integrates seamlessly with your workflow, supporting version control and collaborative editing. Customize themes using your brand color `#3B82F6` for a professional look.

## Quick Start

Get started with Val in minutes.

<Steps>
  <Step title="Create Your Space" icon="plus">
    Sign up at `https://app.val.com` and initialize a new documentation project.
  </Step>
  <Step title="Add Your First Page" icon="file-plus">
    Create `introduction.mdx` with YAML frontmatter.
  </Step>
  <Step title="Customize Branding" icon="palette">
    Set your brand color to `#3B82F6` in theme settings.
  </Step>
  <Step title="Publish" icon="upload-cloud">
    Deploy changes to `https://docs.val.com`.
  </Step>
</Steps>

<CodeGroup tabs="MDX Example">
```mdx
---
title: My Page
description: Page description
---

## Hello World

Welcome to your first Val page!
```
</CodeGroup>

## Brand Guidelines

Follow these guidelines to maintain consistency.

<Callout kind="info">
  Use the primary brand color `#3B82F6` for headings, links, and accents. Avoid using it for backgrounds to ensure readability. Pair with neutral grays for text.
</Callout>

For custom CSS, reference the color as `{brandColor: '#3B82F6'}` in your config.
